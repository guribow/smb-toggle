# SMBToggle

[English](README.en.md)

NAS やほかの Mac の共有フォルダ（SMB 共有）を、メニューバーからマウントしたり取り外したりできるアプリです。同じことができるコマンド `smbctl` も付いています。Finder の「サーバへ接続」を毎回開く必要がなくなります。

- macOS 13 以降で動きます（Apple シリコン・Intel）。
- 日本語と英語に対応しています。アプリもコマンドも、Mac の言語設定に合わせて切り替わります。

## ダウンロードと入れ方

[Releases](https://github.com/guribow/smb-toggle/releases/latest) から zip をダウンロードしてください。`SMBToggle-<版>-ja.zip` には日本語の説明書、`-en.zip` には英語の説明書が入っています。アプリはどちらも同じです。

1. zip を開き、SMBToggle.app を「アプリケーション」フォルダへ移します。
2. ダブルクリックすると「開けませんでした」という警告が出るので、「完了」で閉じます。App Store 以外のアプリなので、最初の 1 回だけ出ます。
3. システム設定の「プライバシーとセキュリティ」を開き、下のほうにある「このまま開く」を押してパスワードを入れます。
4. もう一度ダブルクリックして、「開く」を押します。

メニューバーにドライブのアイコンが出たら準備完了です。新しい版に入れ替えたときは、2〜4 をもう一度行ってください。

## 使い方

- **共有を登録する**：いちばん簡単なのは、Finder の「移動」→「サーバへ接続」で一度つないでから、アイコンの「マウント中の共有を登録」を選ぶ方法です。「共有を追加…」で `smb://ホスト名/共有名` を入力しても登録できます。
- アイコンを押すと、登録した共有が並びます。共有名を押すと、マウントと取り外しが切り替わります。✓ が付いているのがマウント中です。
- 「すべてマウント」「すべて取り外す」で、まとめて操作できます。
- 使っているファイルがある共有は取り外しません。開いているファイルを閉じてから、もう一度試してください。
- アプリを終了しても、マウントした共有はそのまま残ります。

## パスワードについて

このアプリはパスワードを保存しません。macOS の標準の仕組み（NetFS）でつなぎます。

キーチェーンにパスワードがあれば、そのままマウントします。なければ macOS がパスワードを聞いてくるので、「このパスワードをキーチェーンに保存」にチェックを入れておくと、次からは聞かれません。

ユーザー名を指定したいときは、`smb://ユーザー名@ホスト名/共有名` の形で登録してください。

## ターミナルで使う（使わなければ不要）

zip に入っている `smbctl` で、同じことをターミナルから行えます。zip を開いたフォルダで次を実行すると使えるようになります。

```bash
xattr -d com.apple.quarantine smbctl
sudo mkdir -p /usr/local/bin && sudo cp smbctl /usr/local/bin/
```

```bash
smbctl list                          # 登録した共有とマウント中の共有の一覧
smbctl on [名前]                     # マウント（名前を省くと登録した共有すべて）
smbctl off [-f] [名前]               # 取り外す（名前を省くとすべて。-f で使用中でも取り外す）
smbctl toggle 名前                   # マウント・取り外しを切り替える
smbctl add smb://ホスト/共有 [名前]   # 登録する
smbctl remove 名前                   # 登録から外す
```

## 困ったとき

- **「サーバーに接続できません」と出る**：ホスト名を確かめてください。`nas.local` のような名前で見つからないときは、IP アドレスで登録し直してください。
- **マウントしているのに ✓ が付かない**：登録したアドレスと、実際につないだアドレスが違います（IP アドレスと名前など）。登録から外して、「マウント中の共有を登録」で登録し直してください。
- **「ログイン時に起動」でエラーが出る**：システム設定の「一般」→「ログイン項目」に、SMBToggle を手で追加してください。

## 気をつけること

- 登録したサーバーにつなぐだけで、それ以外にデータを送ることはありません。

## 消し方

1. メニューバーのアイコン →「終了」
2. SMBToggle.app をゴミ箱に入れます。
3. 登録した共有の一覧も消すときは、`~/Library/Application Support/smbctl` をゴミ箱に入れます。
4. `smbctl` を入れたときは、`sudo rm /usr/local/bin/smbctl` を実行します。

## ソースからビルドする

Xcode（swiftc）が必要です。

```bash
./build.sh   # アプリと smbctl をビルドして入れる
./dist.sh    # dist/ に配布用の zip を作る
```
